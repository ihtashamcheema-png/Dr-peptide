# Dr. Peptide - Premium Research Peptides E-commerce

A modern, professional e-commerce website for purchasing research-grade peptides. Built with Next.js, React, and Tailwind CSS.

## Features

- 🛒 Complete shopping cart functionality
- 📦 Comprehensive peptide product catalog
- 💳 Checkout system
- 📱 Fully responsive design
- 🔍 Product search and filtering
- 📄 About & Contact pages
- ⚡ Fast performance with Next.js

## Getting Started

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/ihtashamcheema-png/dr-peptide.git
cd dr-peptide

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

## Project Structure

```
src/
├── app/                 # Next.js app directory
├── components/          # React components
├── lib/                 # Utility functions
├── data/               # Product data
└── styles/             # Global styles
```

## Building for Production

```bash
npm run build
npm start
```
